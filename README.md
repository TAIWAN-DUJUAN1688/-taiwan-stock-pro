# 台股日週線買賣雷達 V10.1

## 你要的核心畫面
- K線
- MA5
- MA10
- MA20
- ▲ 買進訊號
- ▼ 賣出訊號
- 🛑 停損價

## 新增
- 日線買賣
- 週線買賣
- 日線 / 週線一鍵切換
- 買進後進入「持有」，不重複買進
- 賣出後回到「空手」，等待下一次買進
- 顯示最近買進日期 / 買進價
- 顯示最近賣出日期 / 賣出價
- 顯示最近買賣紀錄與每次訊號原因

## 買進規則
MA5 上穿 MA20 為主要訊號，並由 MACD、KD 或突破放量至少一項確認。

## 賣出規則
MA5 跌破 MA20，或跌破 MA20 且 MACD 轉空。
持有後若跌破停損價，也觸發賣出。

## 已移除
- 第一目標
- 第二目標
- 目標價風險報酬比

> 日線與週線是獨立交易週期。所有訊號以該根 K 棒收盤確認，不使用未來資料。
