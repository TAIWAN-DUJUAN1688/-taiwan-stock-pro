# 台股獲利策略雷達 V12

## 核心
先驗證策略，再決定是否允許出現買進訊號。

### 驗證門檻
- 至少 4 筆完整交易
- 策略淨報酬 > 0
- Profit Factor >= 1.15
- 勝率 >= 40%
- 策略淨報酬高於同期買進持有

### 策略流程
- 週線定方向
- 日線找 MA10 拉回止穩或突破放量
- MA10 / MA20、MACD、RSI 確認
- 法人籌碼過濾
- 盤整區禁止交易
- ATR 結構停損
- 收盤確認、下一交易日開盤模擬成交
- 回測納入交易成本
- 與買進持有比較

### 畫面
- 是否通過策略驗證
- 目前動作
- 勝率
- 策略淨報酬
- Profit Factor
- 最大單筆虧損
- 買進持有基準
- 策略超額報酬
- ▲買進 / ▼賣出
- 停損價

歷史回測不代表未來績效，也不存在保證獲利的策略。
