# 台股穩健買賣雷達 V11

V11 不再用單一均線交叉直接買賣。

## 核心邏輯
1. 週線定方向：週線多頭才允許新增多單
2. 日線找買點：拉回 MA10 止穩，或突破 20 日高點並放量
3. MA10 / MA20 趨勢確認
4. MACD / RSI 動能確認
5. 法人籌碼過濾
6. 盤整區禁止交易
7. ATR 結構停損
8. 收盤確認，下一交易日開盤才作為模擬成交價

## 圖表
- 台股配色：紅K上漲、綠K下跌
- MA5 黃色
- MA10 藍色
- MA20 紫色
- ▲ 紅色：買進訊號
- ▼ 綠色：賣出訊號

## 回測
顯示：
- 交易次數
- 勝率
- 總淨報酬
- Profit Factor
- 最大單筆虧損
- 最近交易紀錄

回測預設納入買賣手續費與賣出證交稅。
回測結果不代表未來績效。
