### 成交規則
策略訊號於該根 K 線收盤確認，下一根 K 線開盤價作為回測模擬成交價。

### CCI20
CCI20 目前只新增為分析欄位，不會修改 V12 原本買賣策略規則，避免未驗證就改變策略績效。

歷史回測不代表未來一定獲利。
