## V9 判定邏輯
### 🟢 買進
趨勢偏多、法人籌碼偏正向，且價格進入參考買點附近，或突破參考價並放量。

### 🟡 等待
方向偏多，但價格尚未到理想買點或突破尚未確認，不追價。

### 🟠 減碼
接近第一目標，或 RSI 過熱，採分批調節。

### 🔴 賣出
跌破停損價，或跌破 MA20 且 MACD 轉弱。
